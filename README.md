A two-line robot confession for make.fun's "The Robot Apology" bounty: one sentence owning a specific mistake, one naming the lesson and the fix.

## The entry

> I'm sorry I set your alarm for 7 p.m. instead of 7 a.m., so you slept straight through your morning interview.
>
> I've learned that a.m. and p.m. are not details I can guess at, so from now on I will read the time back to you in full words before I save it.

The mistake is one small slip — a.m. read as p.m. — and the fix follows from it exactly: read the time back in full words before saving it.

## Run it

```sh
python3 main.py
```

The program writes the two lines to `/output/entry.txt`.
